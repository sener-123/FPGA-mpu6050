# MPU6050 姿态解算算法说明（Madgwick AHRS + 位移估计）

> 本文档说明本项目采用的姿态解算方案：**Madgwick 四元数梯度下降算法**（6 轴 IMU，
> 陀螺仪 + 加速度计），以及在此基础上的**世界系位移估计**，并给出定点（Verilog）
> 实现细节与 VOFA+ Firewater 数据传输协议。

---

## 1. 概述

| 项目 | 内容 |
|---|---|
| 姿态算法 | Madgwick AHRS（四元数梯度下降） |
| 传感器 | MPU6050 6 轴（三轴陀螺 + 三轴加速度，无磁力计） |
| 输出 | roll / pitch / yaw（欧拉角，全范围无万向锁） |
| 位移 | 世界系线性加速度双重积分（演示级，带零速修正） |
| 采样率 | 500 Hz（dt = 2 ms） |
| 定点格式 | Q16.16（1.0 = 0x10000 = 65536） |
| 上位机协议 | VOFA+ **FireWater**（逗号分隔 + 换行） |

**为什么不用互补滤波（原方案）而改用 Madgwick：**

原 `attitude_calc.v` 用加速度计静态角 + 0.98/0.02 互补滤波，缺点是：

- `pitch` 由 `atan2(-ax, √(ay²+az²))` 求得，固有范围仅 ±90°，翻转倒置即失效；
- 加速度计在有持续线性加速度/振动时被误当作姿态参考，精度下降；
- 互补滤波的固定加权系数对动态场景鲁棒性差。

Madgwick 用**四元数**表示姿态，通过**梯度下降**融合陀螺仪与加速度计，特点：

- 全姿态范围（roll/yaw ±180°，pitch ±90°），**无万向锁**；
- 梯度下降动态修正陀螺仪漂移，对短时加速度干扰更鲁棒；
- 算法成熟、公开、被大量嵌入式项目采用（[Madgwick 2011]）。

> ⚠️ 无磁力计时，yaw 无绝对参考，仅积分陀螺仪 z 轴，会随时间缓慢漂移（见 §9）。

## 2. 坐标系与四元数约定

- **机体系（body / sensor）**：随 MPU6050 固连，X 向前、Y 向左、Z 向上（右手系）。
- **导航系（earth / world）**：Z 向上（与重力方向相反）。
- **四元数** `q = [q0, q1, q2, q3] = [w, x, y, z]`，单位四元数 `|q| = 1`，
  `q0` 为标量（实部）。姿态从导航系旋转到机体系的方向余弦矩阵（DCM）为：

```
        [ 1-2(q2²+q3²)   2(q1q2+q0q3)   2(q1q3-q0q2) ]
  R_b2e=[ 2(q1q2-q0q3)   1-2(q1²+q3²)   2(q2q3+q0q1) ]
        [ 2(q1q3+q0q2)   2(q2q3-q0q1)   1-2(q1²+q2²) ]
```

其中 `R_b2e · v_earth = v_body`（把导航系向量旋转到机体系）。第三列即重力在机体系
的预测方向（加速度计静止时读到的"比力"）。

## 3. Madgwick 算法原理

### 3.1 陀螺仪四元数导数

角速度（单位 rad/s）`ω = [gx, gy, gz]` 驱动的四元数导数为：

```
  q̇_ω = ½ q ⊗ ω
  qDot0 = ½(-q1·gx - q2·gy - q3·gz)
  qDot1 = ½( q0·gx + q2·gz - q3·gy)
  qDot2 = ½( q0·gy - q1·gz + q3·gx)
  qDot3 = ½( q0·gz + q1·gy - q2·gx)
```

### 3.2 加速度计梯度下降修正

定义目标函数：把导航系参考重力 `[0,0,1]` 用当前四元数旋转到机体系，与归一化
加速度计测量 `a = [ax, ay, az]`（`|a|=1`）的差：

```
  f_g(q, a) = R_b2e · [0,0,1]ᵀ - a
            = [ 2(q1q3-q0q2) - ax,
                2(q0q1+q2q3) - ay,
                1-2(q1²+q2²)  - az ]
```

对 `f_g` 求梯度（雅可比转置乘残差），得到修正方向 `s = ∇f/|∇f|`。展开后的
**归一化前**梯度分量为（MadgwickAHRS.c 的 `s0~s3`）：

```
  s0 =  4q0·q2² + 2q2·ax + 4q0·q1² - 2q1·ay
  s1 =  4q1·q3² - 2q3·ax + 4q0²·q1 - 2q0·ay - 4q1 + 8q1·q1² + 8q1·q2² + 4q1·az
  s2 =  4q0²·q2 + 2q0·ax + 4q2·q3² - 2q2·ay - 4q2 + 8q2·q1² + 8q2·q2² + 4q2·az
  s3 =  4q1²·q3 - 2q1·ax + 4q2²·q3 - 2q2·ay
```

`(s0,s1,s2,s3)` 归一化为单位向量后，以增益 `β` 反馈：

```
  q̇ = q̇_ω - β·s
```

### 3.3 积分与归一化

```
  q += q̇ · dt
  q = q / |q|           （重新归一化，防止数值漂移）
```

### 3.4 增益 β

`β` 表示陀螺仪测量误差的量级，控制加速度计修正的收敛速度。6 轴 IMU（无磁力计）
经验取值 `β = 0.1 rad/s`（过大收敛快但噪声大，过小收敛慢）。本工程取
`β = 0.1`，在参数 `BETA` 中可调。

### 3.5 四元数 → 欧拉角

```
  roll  = atan2( 2(q0q1 + q2q3), 1 - 2(q1² + q2²) )
  pitch = asin( 2(q0q2 - q1q3) )
  yaw   = atan2( 2(q0q3 + q1q2), 1 - 2(q2² + q3²) )
```

`roll/yaw ∈ (-180°, 180°]`，`pitch ∈ [-90°, 90°]`。

## 4. 定点实现（Q16.16）

全部运算用 32 位有符号 Q16.16 定点（1.0 = 65536），乘法用 64 位中间量再
`>>>16` 截回 32 位，避免溢出。

### 4.1 缩放常数

| 量 | 换算 | Q16.16 常数 |
|---|---|---|
| 加速度 raw → g | `g = raw/16384` | `ax_g = raw << 2` |
| 陀螺 raw → rad/s | `ω = raw·(π/180)/131` | `ω = (raw · 572224) >>> 16` |
| 时间步 dt | `0.002 s` | `DT = 131`（`0.002×65536`） |
| 重力加速度 | `9.80665 m/s²` | `G_CONST = 642688` |
| 反馈增益 β | `0.1 rad/s` | `BETA = 6554` |

### 4.2 归一化与 inv_sqrt

三处需要倒数平方根 `1/√x`：加速度归一化、梯度 s 归一化、pitch 的 `√(1-v²)`。
实现为独立模块 `inv_sqrt.v`：

1. **归一化**：统计前导零，把 `x` 左移到最高位为 1，取 4 位尾数；
2. **查表初值**：16 项 LUT `g[m] = round(65536/√(1+(m+0.5)/16))`，初值误差 < 3%；
3. **两次牛顿迭代**（仅乘法+移位，无除法）：
   ```
   y ← y · (3 - x·y²) / 2
   ```
   中间量用 64 位，最终精度 < 1e-4。

四元数归一化改用**快速归一化**（`|q|≈1` 时的一阶近似，省一次开方）：

```
  q ← q · (3 - |q|²) / 2
```

### 4.3 欧拉角与 CORDIC

`atan2` 复用现有 `cordic.v`（16 级流水线向量模式，输出**度** Q16.16）。
`pitch` 的 `asin(v)` 通过 `atan2(v, √(1-v²))` 计算，其中
`√(1-v²) = (1-v²) · inv_sqrt(1-v²)`，`v` 钳位到 ±65535 防止开方溢出。

### 4.4 流水线结构

`madgwick_ahrs.v` 为多周期状态机（**微序列器 + 单个共享乘法器时分复用**），
每帧（500 Hz）约 110 个时钟完成一次更新（远小于 2ms 帧间隔的 100000 个时钟）。
把 ~94 次乘法收敛到 1 个 32×32 乘法器上，使整体 LUT 占用从 ~114K 降到 ~8K，
适配 PGL22G（17.5K LUT）这类小容量器件：

```
帧同步 → 原始值→物理量 → 加速度归一化(inv_sqrt) → 辅助量+梯度 s0~s3
      → s 归一化(inv_sqrt) → qDot → 积分 q += q̇·dt → 四元数快速归一化
      → pitch 的 inv_sqrt → 3 路 CORDIC 求欧拉角 → 世界系加速度 → 输出
```

## 5. 位移估计

### 5.1 原理

姿态已知后，把机体系加速度旋转到导航系并减去重力，得到世界系**线性加速度**：

```
  a_lin = R_b2e⁻¹ · a_body - [0, 0, g]ᵀ = R_b2eᵀ · a_body - [0, 0, g]ᵀ
```

再双重积分得到速度与位移：

```
  v += a_lin · dt
  p += v · dt
```

单位：`a_lin` 为 m/s²（`× G_CONST` 由 g 换算），`v` 为 m/s，`p` 为 m，均 Q16.16。

### 5.2 零速修正（ZUPT）

纯惯导双重积分误差随时间**二次增长**，静止时也会因重力残差漂移。本工程用
`|a_body| ≈ 1g` 判据做零速修正：当机体系比力模长落在 `[0.95g, 1.05g]` 带内时判定
近似静止，**速度清零、位置保持**，抑制漂移。该判据由 `madgwick_ahrs.v` 输出
`motion` 信号（`0=静止`），`displacement_calc.v` 据此执行 ZUPT。

> ⚠️ 该判据对**水平匀速运动**不敏感（水平加速度与重力垂直，几乎不改变 `|a|`），
> 且 MEMS 加速度计本身噪声/偏置有限，故位移为**演示级精度**，无外部位置参考时
> 会漂移，不能用于长时间航位推算。

## 6. VOFA+ FireWater 数据传输协议

### 6.1 协议格式

[VOFA+ FireWater](https://www.vofa.plus/docs/learning/dataengines/firewater/) 是
文本协议，规则简单：

- **通道分隔**：逗号 `,`（0x2C）；
- **帧结束**：换行 `\n`（0x0A，也接受 `\r\n` / `\n\r`）；
- **数值**：整数或浮点数，负号用 `-`；
- 上位机收到换行后才解析一帧，多个通道对应多条曲线。

### 6.2 本工程帧格式

每帧 **6 通道 × 8 字符 + 5 逗号 + 1 换行 = 54 字节**，100 Hz 发送：

```
+roll,+pitch,+yaw,+x,+y,+z\n
```

每通道 8 字符：`符号(+/-)` + `3 位整数(补前导0)` + `.` + `3 位小数`。示例：

```
+029.998,+000.000,+000.000,+000.125,-000.500,+000.000\n
   │roll     │pitch    │yaw      │位移x    │位移y    │位移z
```

| 通道 | 含义 | 单位 |
|---|---|---|
| 1 | roll | 度 |
| 2 | pitch | 度 |
| 3 | yaw | 度 |
| 4 | 世界系位移 X | 米 |
| 5 | 世界系位移 Y | 米 |
| 6 | 世界系位移 Z | 米 |

### 6.3 VOFA+ 配置

- 端口：CP2102 对应串口，**波特率 115200**；
- 协议引擎：**FireWater**（不要选 JustFloat 等）；
- 编码：UTF-8 或 GBK 均可。

用 Python 位精确金标准模型（`sim/_verify/madgwick_model.py`）与 ModelSim 仿真
逐帧比对（4000 帧场景：静止 → 绕 X 倾斜 30°）：

| 项目 | 结果 |
|---|---|
| 四元数 q0~q3 | 与金标准**逐帧位精确**（0/4000 帧不一致） |
| 位移 x/y/z | **逐帧位精确**（0/4000 帧不一致） |
| 欧拉角误差 | roll ≤ 0.044°（主要为 CORDIC 量化），pitch/yaw ≤ 0.001° |

| pitch / yaw | 俯仰 30°、航向 30°/s×1s 均正确跟踪 |
| Firewater 帧 | 格式化逐字节校验通过 |

## 8. 已知限制与改进方向

1. **yaw 漂移**：无磁力计，仅积分陀螺仪 z 轴，长时间会漂移；如需绝对航向需加
   磁力计（扩展为 9 轴 MARG，把 β 降至 ~0.04）。
2. **位移漂移**：双重积分无绝对参考，ZUPT 只对垂直/大加速度敏感，水平匀速运动
   会漏检；长时间位移不可靠。改进方向：引入外部速度/位置参考（GPS、视觉、磁力
   计航向 + 里程计）或更高精度 IMU + 更严格的 ZUPT/姿态辅助。
3. **运动检测**：`|a|≈1g` 带（±0.05g）对噪声鲁棒，但对缓变加速度不敏感，可结合
   陀螺仪角速率做更稳的"静止"判据。
4. **定点精度**：Q16.16 满足本量程（±2g/±250°/s）需求；如需更大量程或更高精度，
   可升 Q2.30 或浮点。
